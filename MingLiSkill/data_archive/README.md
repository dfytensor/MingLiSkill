# data_archive 数据集说明

本目录存放全球命理师大赛（hkjfma.org）真题的结构化数据与全部实验产物。

## 文件清单

### 题库类

| 文件 | 内容 | 规模 |
|------|------|------|
| `asklingxi_answers.json` | 17 届（2010-2026）官方答案序列，按届存储 | 555 题 |
| `master2.json` | 每届：命例四柱（乾造/坤造）+ 按题号对应的官方答案 | 115 命例 |
| `dataset555.json` | 逐题记录：届次/题号/官方答案/命例四柱/题干年份/答案选项年份 | 512 条 |
| `official_answer_keys.json` | 2018/2023/2024 三届官方答案（hkjfma.org 官方答案图 OCR，含与 MingLi-Bench 的交叉验证结论） | 120 题 |
| `../comp2019_questions.json` | 2019 第十届完整题面（8 命例 × 5 题，含双胞胎对照命例） | 40 题 |
| `../comp2020_questions.json` | 2020 第十一届完整题面（8 命例 × 5 题，含 23:50 子时案例） | 40 题 |
| `../new_bench/bench2021_questions.json` | 2021 第十二届题面+答案 | 40 题 |

### 实验产物类

| 文件 | 内容 |
|------|------|
| `feature_stats.json` / `sig_feats.json` | 109 个事件年样本的 17 特征统计检验（结论：全部 lift≈1.0） |
| `rows555.json` / `master_raw.json` | 中间解析产物 |
| `asklingxi_html/` | 17 届页面原始 HTML 缓存（可复现提取） |
| `../preregistered_predictions.json` | 预注册预测（git `44151f4` 锁定，判分 21/70=30.0%） |

## 字段说明（dataset555.json）

```json
{
  "y": "2019",              // 届次
  "qnum": 1,                // 题号(1-40)
  "ans": "C",               // 官方答案字母
  "pillars": ["辛酉","辛丑","丙午","己丑"],  // 命例四柱(年月日时)
  "years_in": [1991, 1997], // 题干+选项中出现的年份
  "ans_year": 1997          // 正确答案选项中的年份(事件年题才有)
}
```

## 数据质量

- 2023/2024 两届答案已与 hkjfma.org 官方答案图逐字交叉验证（40/40 × 2 一致）
- 豆瓣/知乎第三方转载与官方答案比对一致
- MingLi-Bench 基准标签经官方答案验证 80/80 零错误

## 引用

若使用本数据集，请注明来源：香港青年术数家协会全球命理师大赛（hkjfma.org），
结构化版本见本仓库。
