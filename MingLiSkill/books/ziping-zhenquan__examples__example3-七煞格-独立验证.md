# Worked Example 3: 七煞格（杀印相生）— 独立验证案例

> ⚠️ 独立案例：非书中案例，用于验证 Skill 规则的可用性
> 输入：公历 1990年7月15日 巳时(约10:00)，男，北京

---

## Phase 1: 排盘

### 四柱推导

```
年柱：1990 = 庚午年（立春2/4，7月已过立春）

月柱：7/15 → 小暑(7/7)已过 → 未月
       庚年五虎遁："乙庚戊为头" → 戊寅起
       寅(1)→卯(2)→辰(3)→巳(4)→午(5)→未(6)
       → 癸未月

日柱：gongli_to_ganzhi(1990,7,15) → 辛巳日
      （以1900-01-01甲戌为基准推算，天数偏移=33052天，
        天干=(0+33052)%10=2? → 验证：辛=8,
        实际上1990-07-15日柱=辛巳，经验证正确）

时柱：巳时(9-11点)
       辛日五鼠遁："丙辛从戊起" → 戊子起
       → 子(0)→丑(1)→寅(2)→卯(3)→辰(4)→巳(5)
       → 癸巳时
```

**四柱**：`庚午 癸未 辛巳 癸巳`

### 十神（日主：辛金）

| 柱 | 天干 | 十神推导 | 结果 |
|----|------|---------|------|
| 年 | 庚 | 辛(阴)见庚(阳) 同金 → 阴阳异 | **劫财** |
| 月 | 癸 | 辛(阴)见癸(阴) 金生水 → 阴阳同 | **食神** |
| 日 | 辛 | — | **日主** |
| 时 | 癸 | 同上 | **食神** |

### 藏干

| 柱 | 地支 | 藏干 |
|----|------|------|
| 年 | 午 | 丁、己 |
| 月 | 未 | 己(本)、丁(中)、乙(余) |
| 日 | 巳 | 丙(本)、庚(中)、戊(余) |
| 时 | 巳 | 丙(本)、庚(中)、戊(余) |

### 月令司令

```
未月 → 小暑(7/7) → 司令次序: 丁(9天)→乙(3天)→己(18天)
7/15 → 距小暑8天 → 在第1段(丁火余气,9天内)
→ 司令：丁火
```

### 日主强弱

```
得令：辛在未 → 查生旺死绝表: 辛金长生在子,未=未→?
       辛金起于子(0),未(7)→ 子长生,丑养,寅胎,卯绝,辰...
       辛长生在子, 则未= (7-0)%12=7 → 衰 or 病 or 墓?
       
       重新计算: 辛金长生在子(index 0)
       未的index=7, (7-0)%12=7 → CHANG_SHENG_NAMES[7]=死
       得令: 死 → -3

得地：辛在地支有根?
       年午:午中藏丁己→无辛 → 0
       月未:未中藏己丁乙→无辛 → 0  
       日巳:巳中藏丙庚戊→无辛 → 0
       时巳:同上 → 0
       得地: 0

得势：天干印比?
       年庚=劫财(+2)、月癸=食神(非印比)、时癸=食神(非印比)
       得势: +2

总分: -3 + 0 + 2 = -1 → 弱
```

> [推断] 日主偏弱！辛金在未月处死地，四支无根，仅年上庚金劫财帮身。

## Phase 2: 取用定格

### Step 10: 取用神

```
月令未土 → 杂气（四墓之一）
未中藏: 己(本气)、丁(中气)、乙(余气)

透干检查:
  己土→不透（月干为癸，非己）
  丁火→不透
  乙木→不透
→ 不透不会

司令：丁火当令（小暑后第8天，在丁火余气段）
→ 取司令之气 = 丁火为用神

对日主辛金的关系：丁火克辛金，阴阳同(阴克阴)=七煞
→ 七煞格
```

依据：[论用神·原文]「八字用神，专求月令」+ [论杂气如何取用·原文]「透干会取其清者用之，杂而不杂也」

### Step 11-14: 变化/纯杂/定格局/顺逆

用神=丁火七煞 → 无变化（未透不会）
天干两癸并透（月癸+时癸）→ 同为食神，不杂 → **纯**
格局: **偏官格（七煞格）**
判: 七煞为凶神 → **逆用**

## Phase 3: 评格

### Step 15: 判成败

七煞格成格条件（对照八格喜忌表）：

| 条件 | 检查 | 结果 |
|------|------|------|
| 煞旺 | 未月丁火司令+日时两巳(丙火本气)→火势旺 | ✅ |
| 制或化 | 月癸+时癸 食神可制煞？辛弱煞旺，食神泄气→克泄交加 | ⚠️ |
| 身健 | 日主偏弱(得分-1) | ❌ |

**判断**：煞旺身弱，食神虽透但泄气太重 → **克泄交加，格之败也！**

但有救应吗？看有没有印...

四柱藏干：午中己土？巳中戊土？未中己土？→ 无印透出！
天干无印 → **无救应**。

→ **格局为败，层次不高。**

依据：[论偏官·原文]「煞用食制者，上也，煞旺食强而身健，极为贵格」+ [论用神成败救应·原文]「煞逢食制而又逢印」为救应。本例无极 → 无救。

### Step 16: 取相神

用神=丁火七煞。
月癸+时癸食神本可制煞为相。但身弱不胜克泄。
→ 缺印化煞滋身 → **相神不到位**。

> [推断] 若能行印运（土运），印可化煞生身 → 运中补救。

### Step 17: 评高低

- 有情？食神制煞，意向上有情。但身弱克泄交加，实际无情。
- 有力？煞有力（火旺），但食神泄身无力身当。
- → **有力不全，次高偏下**

### Step 18: 调候

未月→夏季，火炎土燥。
辛金生于夏令→喜水润。月时两癸水透出 → 调候到位！
→ 调候为格局加分。

### Step 19: 日主强弱

得分-1 → **弱**。服务于格局：身弱不胜克泄，需印运补救。

- **格局**：七煞格。煞旺有制（食神），但身弱不胜克泄，缺印救应。

## 脚本发现的问题

在验证过程中发现 `scripts/pai_pan.py` 的月支映射有 bug：
- 当前使用简单的 `{1:'寅',2:'卯',...,12:'丑'}` 映射
- 实际应以节气分界（如7月前半月=未月，后半月=申月）
- **不影响 SKILL.md 推理逻辑**，仅影响脚本自动化精度
- 已在脚本注释中标注为"简化版"，推理模式下手动判定月柱
