# 现代场景参数化模块

> 核心方法论：八字是「分类器」而非「身份证」——同一配置因社会场景不同而吉凶反转。
> 本模块的任务：为每一句古典断语挂载3-7个现代场景，建立「场景探测→判断分流」机制。

---

## 第一章：核心方法论——为什么八字需要场景参数化

### 1.1 古典断语的隐含前提

每一句古代口诀，背后都有一个「默认社会场景」：

```
伤官见官，为祸百端
→ 隐含前提：你在科层制度下讨生活，官是你的上级，伤官是你怼他
→ 当这个前提不成立时，断语需要重新判断而非直接套用
```

### 1.2 场景参数化的三层操作

```
第一层：识别断语的【古代默认场景】是什么
第二层：列出该断语在【现代社会】可能出现的所有场景
第三层：为每个现代场景给出【分流判断】，而非单一结论
```

### 1.3 使用方法

论命中每次引用古典断语时，按以下三步操作：
1. 读断语 → 定位其【古代默认场景】是什么
2. 查本模块对应章节 → 找到用户所处的【现代场景】
3. 输出该场景下的【分流判断】，不输出古代原话

当某个断语在本模块中无对应条目时，说明它尚未经过场景化审核，此时应标注"此断语尚未完成现代场景映射，以下判断基于古典默认场景，仅供参考"。

## 第三章：核心断语现代场景分流表

> 本章每一条断语均对应《八字论命操作手册》中的相关章节。方括号内为手册出处。

### 3.1 「伤官见官，为祸百端」[手册 2.2 伤官格、6.5 官非]

| 场景 | 现代判断 |
|------|---------|
| 公务员/国企员工 | ⚠️ 大概率凶——顶撞领导被穿小鞋。科层制下官星至上 |
| 私企员工 | ⚠️ 看情况——伤官=创新但取决于老板格局 |
| 自由职业者/个体户 | ✅ 不凶反吉——特立独行是卖点，没有明确的"官"可以伤 |
| 打官司/维权 | ✅ 可能胜诉——伤官=辩论能力，对方是"官"你来伤他 |
| 创业者 | ✅ 适合破局——伤官=颠覆创新，没有上级只有市场 |
| 自媒体/网红 | ✅ 越争议越火——伤官=流量，争议就是关注度 |
| 学生/考试 | ⚠️ 看情况——标准化考试的"官"是考场规则，伤官=不守规矩可能被判违规 |
| 学中医/传统技艺 | ⚠️ 看情况——师承体系仍有"官"，质疑师父可能不利 |
| 学术界 | ⚠️ 看情况——挑战权威可能被封杀或一战成名 |

**判断分流流程**：
```
伤官见官 → 
  ├─ 被问人是否有明确的"上级/规则执行者"？
  │   ├─ 有 → 传统"为祸"仍需警惕
  │   └─ 没有 → 释放正向创造力
  ├─ "官"是规则的执行者还是竞争对手？
  │   ├─ 执行者（领导/考官/监管）→ 避其锋芒
  │   └─ 竞争对手（对手律师/对家）→ 发挥伤官
  └─ 是否为金水伤官？（金水伤官见官反贵，调候优先）
```

| 设计师 | 伤官+财 | 伤官=创造力；财=商业变现 |
| 销售/BD | 偏财+食神 | 偏财=业绩提成；食神=沟通表达 |
| 公务员 | 正官格+印护 | 正官=体制；印=学历背景 |
| 创业CEO | 七杀格+食制/从格 | 杀=竞争/冒险；食=产品和团队 |
| 自由职业者 | 伤官+财/建禄用财 | 伤官=独立；财=直接变现 |
| 科研人员 | 偏印+食神 | 偏印=深度研究；食神=论文输出 |
| 艺术家/音乐人 | 伤官旺/食神吐秀 | 伤官=独创性；食神=审美 |
| 电商运营 | 偏财+食神 | 偏财=利润波动；食神=运营能力 |
| 程序员→技术总监 | 食神→七杀运 | 从技术输出到管理决策 |

### 4.4 创业成功率的场景参数

传统的「财格+食神生财=经商有成」在现代需要加上：

| 传统条件 | 现代附加条件 | 判断 |
|---------|------------|------|
| 财格身强 | +行业选择正确 | 身强力能扛，但选错行业也白搭 |
| 食神生财 | +技术壁垒/网络效应 | 古代一个手艺能传三代，现代需持续创新 |
| 财通门户 | +资本支持/人脉资源 | 古代经商自有资金即可，现代多数需要融资 |
| — | +合规经营能力 | 古代税收简单，现代合规成本高 |
| — | +抗风险能力（储蓄/保险） | 古代风险天花板低，现代可以赔到倾家荡产 |

**创业成功的现代加分项**（原局配合大运判断）：
- 有食伤（产品/技术）→ 基础分
- 有财星（变现）→ 加1级
- 有七杀（敢于冒险）→ 加1级
- 有印星（学习迭代能力）→ 加1级
- 原局"病"被大运"药"去 → 再加1级

### 4.5 数字时代的社会结构变化：对八字职业判断的系统性修正

以下五项变化不是新职业，而是**底层社会结构的变化**——它们改变了十神的含义和权重，影响所有职业方向的判断。

---

**变化一：远程工作 →「驿马」的含义从负面转为中性/正面**

| 维度 | 古代 | 现代 |
|------|------|------|
| 驿马的含义 | 奔波劳碌、背井离乡（偏负面） | 可以选择居住地、不受地域限制（中性/正面） |
| 时柱逢驿马 | "到老奔波" | 可能有海外工作/数字游民的机会。一生有跨地域流动的自由 |
| 驿马+财星 | 在外经商发财但不稳定 | 远程高薪工作/全球客户/跨境电商——稳定和自由可以兼得 |
| 驿马+官星 | 外放做官、背井离乡 | 在国际公司/远程团队中担任管理岗位 |

**判断修正**：论命中遇到驿马，默认不再说"奔波劳碌"。先确认用户的职业模式——远程/自由职业者、远程/自由职业者的驿马是"选择权"而非"被迫"。

---

**变化二：零工经济 →「正财」与「偏财」的二分法需要增加第三类**

| 收入模式 | 古代对应 | 传统十神 | 现代对应 |
|---------|---------|---------|---------|
| 固定月薪（单一雇主） | 俸禄 | 正财 | 正财 |
| 经商利润（自有资本） | 买卖差价 | 偏财 | 偏财 |
| **多客户/项目制/平台接单**（非雇员也非资本家） | —（不存在） | — | **正财+偏财的混合体**。收入来源多但不靠资本，靠技能×渠道 |

**判断修正**：身强+财星混杂（正偏财并透）在现代可能不是"财多身弱/富屋贫人"，而是"多元化收入"。判断步骤：
1. 先问收入结构：单一工资还是多来源？
2. 多来源 + 身强 = 抗风险能力强，财星混杂是优点而非缺点
3. 多来源 + 身弱 = 仍是"贪多嚼不烂"

---

**变化三：AI 自动化 →「印星」（持续学习能力）的职业权重上调**

| 维度 | 古代 | 现代 |
|------|------|------|
| 一项技能的生命周期 | 一辈子，可传三代 | 3-5 年。技术栈持续更新 |
| 食伤（技能）的价值 | 恒定。会打铁就是打铁匠 | 递减。去年的框架今年可能被替代 |
| 印星（学习能力）的价值 | 辅助。考完功名就不需要了 | **核心资产**。唯一不贬值的能力是学习新东西的能力 |

**判断修正**：在职业方向判断中，**偏印有根**（自学能力）的权重从"加分项"上调为"基础项"。没有印星的命局在现代职场面临的不是"笨"的问题，而是"学不动"的问题——这比古代严重得多。

具体调整：
- 原局无印 + 大运无印 → 建议选择技术迭代慢的行业（如医疗、法律、手工艺），避免进入快速迭代的纯技术领域
- 偏印有根 → 适合 AI/技术/研究等需要持续自学的方向
- 正印有根+官星 → 适合需要持续考证/资格认证的体制内技术岗位

---

**变化四：创作者经济 →「伤官生财」的上限被互联网放大**

| 维度 | 古代上限 | 现代上限 |
|------|---------|---------|
| 伤官（创意输出）的受众 | 一个村/镇 | 全球 |
| 伤官生财的变现速度 | 以年计（口碑传播） | 以天/小时计（算法推荐） |
| "伤官伤尽"在古代被否定 | 徐乐吾："但有贫贱，并无富贵" | 自媒体时代反而可能成立——没有官星约束的表达自由 = 流量来源 |

**判断修正**：
- 伤官旺 + 有财星转化 → 在古今都是好配置。但现代的上限大幅提高：不是"手艺人"而是"内容品牌"
- 伤官旺 + 无财无印（"伤官伤尽"在古代被否定）→ 在现代的"自媒体/内容创作"场景下需要重新评估。若大运有火土通关（印/财到位），可以是将内容力转化为商业价值的路径
- 伤官见官在大厂/体制内仍凶，但在内容创作/自媒体场景下 → 见 3.1 节分流表

---

**变化五：平台经济 →「官杀」增加了"平台规则"这一层现代含义**

| 古代官杀含义 | 现代新增含义 |
|------------|------------|
| 朝廷/官府/上级 | 平台算法、App Store 审核、支付风控、行业监管 |
| 科举功名 | 平台认证/蓝V/官方推荐 |
| "官杀混杂"在古代=多头领导 | 同时在多个平台运营（公众号+抖音+小红书）= 多平台规则约束 |

**判断修正**：
- 平台从业者（自媒体/电商/开发者）的"官杀"要按"平台规则"来理解，而非传统"领导"
- 官杀混杂 + 平台从业者 → 不一定是"多头领导压力"，可能是"多平台分散风险"
- 官星为忌 → 平台规则对你不友好（限流/封号风险）。建议选择规则宽松的平台或去中心化方向

### 4.7 不同创业类型在现代的八字判断差异

拓展 4.4 节。同样的"财格+食神生财"，不同创业类型的成功条件完全不同：

| 创业类型 | 核心格局要求 | 现代附加条件 | 最容易失败的命局特征 |
|---------|------------|------------|-------------------|
| **科技创业**（SaaS/AI/软件） | 偏印（技术壁垒）+食神（产品）+偏财（融资/退出） | 快速迭代能力（印）、团队协作（比劫为喜时） | 印弱无根+伤官见官——有创意但学不动，与大厂竞争必败 |
| **内容创业**（自媒体/视频/播客） | 伤官（内容力）+财星（变现）或食神（稳定输出） | 平台选择（官杀=平台规则）、抗算法波动（七杀承受力） | 伤官旺无财转化——有内容但变不了现，纯粹为爱发电 |
| **电商/跨境电商** | 偏财+食神+驿马 | 供应链管理（土=稳定）、选品眼光（偏印=数据能力） | 财多身弱——流水大利润薄，富屋贫人 |
| **实体创业**（餐饮/零售/制造） | 财格+正财有根+土厚（稳定运营） | 选址（驿马/地域选择）、合规（官星）、现金流（财星不虚浮） | 财星虚浮坐劫财——钱还没到手就被各种成本吃掉 |
| **服务创业**（咨询/设计/法律） | 食神+印星（专业权威）+官星（行业资质） | 个人品牌（伤官或食神透干）、转介绍网络（比劫） | 食伤混杂无制——什么都会什么都不精 |
| **Web3/加密创业** | 偏财极旺+七杀+偏印 | 高风险承受（七杀）、去中心化思维（偏印克正印=反传统）、社区运营（比劫） | 财杀过旺日主无根——不是从格就是倾家荡产 |

**结论**：现代论命中遇到"创业"两个字，不能再简单套用"财格身强=经商有成"。必须先确认创业赛道，再用对应的格局配置做判断。

## 第五章：婚姻家庭现代化

### 5.1 配偶星/宫的场景化

| 古典断语 | 古代默认场景 | 现代场景重映射 |
|---------|------------|--------------|
| "正财为妻，偏财为妾" | 一夫多妾制 | 正财=正缘/配偶；偏财=恋爱对象/前任。废除"妾"概念 |
| "女命官杀混杂，夫多淫乱" | 一女不可事二夫 | 多段恋爱经历（正常）、婚内出轨（仍凶）。区分"婚前多段感情"与"婚内不忠" |
| "日坐伤官，克夫" | 女命依附丈夫生存 | 女强人/独立女性 = 伤官生财自己赚钱 = 不克夫，是"不靠夫" |
| "妻宫坐阳刃，克妻" | 妻无经济独立权 | 身弱用刃+妻宫坐刃 → 妻能力强反而能帮夫。区分"克"和"管" |
| "配偶宫被冲，婚姻不稳" | 终身不离婚 | 现代社会离婚率本身就高。冲=婚姻有波动，可能是离婚也可能只是异地/吵架 |

### 5.2 晚婚/不婚的现代解读

传统"婚姻不实"或"晚婚"在现代可能是：
- 主动晚婚（先搞事业）→ 非凶
- 不婚主义 → 生活方式选择
- 同性恋 → 传统八字完全不覆盖（需注明"此体系不覆盖"）
- 丁克家庭 → 不能说"无子=无后为大"

### 5.3 「合婚」的现代修正

「吕才合婚书」以年命纳音论婚配之法已被神峰通考明确批驳，本手册不采信。现代的合婚参考：
- 五行协调 > 年命纳音
- 价值观/性格匹配（从五行性情推断）> 属相六冲
- 沟通模式（从十神互动推断）> 神煞匹配

### 5.4 「日坐伤官，克夫」→ 现代分流 [手册 6.2]

**古代默认场景**：女命无经济独立权，一生依附丈夫。伤官克制正官（夫星）= 反抗丈夫权威 → "克夫"。这个"克"的本质是**不服从**，不是"害死"。

| 现代场景 | 分流判断 |
|---------|---------|
| 职业女性/自己赚钱 | ✅ 不克夫，是"**不靠夫**"。伤官=独立性和能力，伤官生财=自己就是生产力。不是克谁，是不需要被养 |
| 创业者/自由职业 | ✅ 伤官生财，才华变现。她的"伤官"冲着事业去了，不是冲着丈夫。格局中若有财星通关，伤官→财→官，反而旺夫 |
| 学术/技术专家 | ✅ 伤官佩印，才华有约束。印星克制伤官的同时保留了创造力，对婚姻的攻击性大幅降低 |
| 全职主妇/经济依赖配偶 | ⚠️ 传统"克夫"风险部分成立。经济不独立的场景下，伤官的攻击性无处释放，容易在夫妻关系中爆发 |
| 伤官见官（原局官星透干被伤） | ❌ 这是真凶配置。不论什么场景，伤官直接克原局正官都是婚姻硬伤。大运流年引动时尤甚 |

**判断分流流程**：
```
日坐伤官 →
  ├─ 原局有财星通关？（伤官→财→官）
  │   ├─ 有 → 伤官被财转化, 不生是非只生钱。"你不是克夫, 你是旺自己。"
  │   └─ 无 → 继续判断
  ├─ 原局有印星制伤？（伤官佩印）
  │   ├─ 有 → 有才华有约束, 不会无差别攻击夫星。
  │   └─ 无 → 传统风险上升
  ├─ 原局官星是否透干？
  │   ├─ 透干且被伤官所克 → 真"伤官见官", 婚姻硬伤
  │   └─ 不透 → 伤官没有明确攻击目标, 风险可控
  └─ 场景确认: 你自己赚钱还是靠配偶？
      ├─ 自己赚钱 → "你这个不叫克夫, 是你自己太能干了。"
      └─ 靠配偶 → "需要注意夫妻关系中的话语权平衡。"
```

### 5.5 「女命官杀混杂，夫多淫乱」→ 现代分流 [手册 2.2、7 裁决1]

**古代默认场景**：一女不可事二夫，婚前婚后都只能有一个男人。官杀混杂 = 多个男人 = "淫乱"。

| 现代场景 | 分流判断 |
|---------|---------|
| 婚前多段恋爱 | ✅ 正常。现代社会婚前恋爱是试错过程，不等于"淫乱"。官杀混杂 + 无制 → 感情经历多但最终能选对 |
| 婚内出轨 | ❌ 仍凶。无论什么时代，配偶星混杂 + 配偶宫被冲破 + 岁运引动 = 婚外情的结构风险仍在 |
| 同时有正官和七杀（体制内外双重身份） | △ 不一定是感情问题。官杀在现代也代表"多个老板/多个甲方/兼职+主业"。先排除职业含义再论婚姻 |
| 官杀混杂但有印化 | ✅ 有救。印星转化官杀 → 多段感情经历但最终都能学到东西，不是"淫乱"是"成长" |
| 官杀混杂但有合去其一 | ✅ 有救。合官留杀或合杀留官 = 感情虽有波折但最终取清 |

**判断分流流程**：
```
女命官杀混杂 →
  ├─ 第一步：排除职业含义
  │   ├─ 该命主是否身兼多职/多方汇报/体制内外混搭？
  │   │   └─ 是 → 官杀混杂可能指向工作而非感情。先确认场景再判
  ├─ 第二步：看有无制化
  │   ├─ 有印化 → "经历多人但最终能找到自己的路。"
  │   ├─ 有合去 → "有波折但总会取清。"
  │   └─ 无制无化 → 风险上升
  ├─ 第三步：场景确认
  │   ├─ 问婚否？（通过自然对话确认，不是直接问）
  │   │   ├─ 已婚 → "婚姻中需要注意边界感。"
  │   │   └─ 未婚 → "你感情经历可能比一般人多，这本身不是坏事，关键在选对人。"
```

### 5.6 「配偶宫被冲，婚姻不稳」→ 现代分流 [手册 6.2]

**古代默认场景**：不允许离婚，婚姻"不稳"的唯一含义是配偶早逝或被休。

| 现代场景 | 分流判断 |
|---------|---------|
| 异地/分居（非感情破裂） | △ 正常波动。现代职业导致的异地分居 ≠ 婚姻破裂。冲=动，可能是因工作/求学两地分居 |
| 离婚 | ⚠️ 可能性高于常人。日支逢冲 + 岁运引动 = 婚姻结构的剧烈变动。但现代社会离婚≠人生失败 |
| 频繁吵架但不离婚 | △ 冲=冲突。有些夫妻冲一辈子但不离，取决于原局有无合来稳住 |
| 配偶宫被冲但有合来解 | ✅ 有救。冲被合解 → 虽有波动但最终稳住。如寅申冲而有亥合寅 → 冲被化解 |
| 日支为喜神被冲 | ❌ 严重。喜神被冲 = 婚姻支柱被动摇 |
| 日支为忌神被冲 | ✅ 反而是好事。忌神被冲去 = 婚姻枷锁被打破 |

**判断分流流程**：
```
配偶宫被冲 →
  ├─ 有无合来解冲？
  │   ├─ 有 → "婚姻有波动但不会散。"
  │   └─ 无 → 冲的力量完全释放
  ├─ 日支是喜是忌？
  │   ├─ 喜神 → "婚姻是你的支撑, 需要特别用心维护。"
  │   └─ 忌神 → "这个冲对你来说反而是解脱。"
  ├─ 冲的来源（大运/流年/原局）？
  │   ├─ 原局自带 → 一生婚姻有波动, 但已内化为常态
  │   ├─ 大运来冲 → 十年内有婚姻变化
  │   └─ 流年来冲 → 当年的婚姻事件
  └─ 场景输出: "这步运/这一年, 你的婚姻可能会有一个比较大的变化——可能是异地、可能是关系的重新定位、也可能是分开。现代人不把离婚当世界末日, 关键是你准备好了没有。"
```

### 5.7 「配偶宫空亡，婚姻不实」→ 现代分流 [手册 6.2、8.1 旬空]

**古代默认场景**：人人都要结婚，不婚=不正常。"空亡"="没有"。

| 现代场景 | 分流判断 |
|---------|---------|
| 主动晚婚（搞事业） | △ 不是"空"，是主动选择。配偶宫空亡 + 财官有力 = 先立业后成家 |
| 不婚主义 | ✅ 空亡的现代合理表达。不想结婚是个人选择，不是"婚姻失败" |
| 形婚/表面婚姻 | ⚠️ 空亡的真正含义：有形式无实质。法律上是夫妻但没有真实的婚姻生活 |
| 配偶长期不在身边 | ⚠️ 空亡的另一层：有配偶但"空"——异地、分居、情感疏离 |
| 填实之年成婚 | ✅ 空亡≠永远空。岁运填实（大运/流年支恰好是空亡之支）= 婚动之年 |

**判断分流流程**：
```
配偶宫空亡 →
  ├─ 岁运何时填实？
  │   ├─ 大运支 = 空亡之支 → 此运婚动
  │   └─ 流年支 = 空亡之支 → 此年婚动
  ├─ 场景确认
  │   ├─ 你想结婚吗？
  │   │   ├─ 想 → "你的正缘来得晚一些, [填实之年]前后概率最大。"
  │   │   └─ 无所谓 → "空亡在配偶宫, 你对婚姻的需求本来就不强。这不是缺陷, 是特质。"
  └─ 输出铁律: 永远不要说"你一辈子结不了婚"。
      空亡可填实, 晚婚≠不婚, 不婚≠失败。
```

### 5.8 「日坐阳刃，克夫/克妻」→ 现代分流 [手册 6.2]

**古代默认场景**：阳刃=刚暴, 日坐阳刃=配偶被"克"（压制）。

```
  │   ├─ 身弱用刃 → "配偶反而是你的贵人。"
```

### 5.9 「官星被合/夫星被合」→ 现代分流 [手册 2.0 天干五合]


## 第七章：健康与寿元的现代解读

### 7.1 五行配脏腑的现代医学对应

| 五行 | 传统脏腑 | 现代对应 |
|------|---------|---------|
| 木 | 肝胆 | 肝胆功能+神经系统（肝主筋） |
| 火 | 心/小肠 | 心血管+循环系统 |
| 土 | 脾胃 | 消化系统+免疫系统（脾主运化） |
| 金 | 肺/大肠 | 呼吸系统+皮肤（肺主皮毛） |
| 水 | 肾/膀胱 | 泌尿系统+内分泌/生殖 |

### 7.2 「夭寿」判断的现代修正

古代「夭」= 未成年死亡或早逝。现代医学大幅延长了寿命：
- 原局出现「夭寿之象」（日主无根+大运再走死绝之地）时，应表述为"健康严重受损风险高、特定年龄段需重点防范"，而非"短命"
- 输出时加入具体提醒："此阶段建议每年体检重点检查[对应五行脏腑]，现代医学可大幅干预"

### 7.3 健康论断输出措辞规范

八字健康判断的核心原则：**八字给出的是倾向性信号，不是诊断。AI 输出的是风险提示，不是医学结论。**

| 输出场景 | ❌ 禁止表述 | ✅ 正确表述 |
|---------|-----------|-----------|
| 某五行受克重 | "你的肝会出问题" | "肝胆功能是你需要长期关注的方向，建议定期体检" |
| 调候失调 | "你这个体质一辈子好不了" | "你属于偏寒/偏燥体质，生活方式上注意[具体建议]" |
| 夭寿之象 | "短命"、"活不过XX岁" | "XX岁到XX岁之间是健康的关键窗口期，及早干预可以大幅改善" |
| 某大运健康差 | "这十年你会生大病" | "这步大运身体负担加重，需要比平时更注意[具体脏腑]" |
| 金木交战 | "会出车祸" | "金木相战之年注意骨骼关节和交通安全" |
| 水火不济 | "心脏会出问题" | "心血管和睡眠质量在这阶段需要特别关注" |

**输出铁律**：
1. 永远说"风险/倾向/需要关注"，不说"一定会"
2. 每次健康提示必须附一句现代医学建议（"建议体检"、"可咨询医生"）
3. 不说精确时间（"XX岁"），说"XX岁到XX岁之间的阶段"
4. 不说死——"短命"、"活不长"、"夭折"等词永远禁用
5. 不替代医生——结尾加一句"以上为命理分析，身体问题请就医检查"

## 第九章：灾祸/官非的现代形态

### 9.1 古代「灾祸」→现代场景

| 古代断语 | 古代所指 | 现代场景 |
|---------|---------|---------|
| 日犯岁君 | 冲撞太岁/官府 | 违反法规被处罚/得罪有权力的人 |
| 伤官见官 | 被官府治罪 | 社交媒体言论失当/违反平台规则被封 |
| 官杀攻身 | 被官府追捕 | 被起诉/被仲裁/被合规调查 |
| 枭神夺食 | 才华被扼杀 | 知识产权被盗/被雪藏/被封杀 |
| 比劫夺财 | 被抢劫 | 被诈骗/投资暴雷/合伙人卷款 |
| 金火相战 | 刀兵之灾 | 手术/交通事故/肢体冲突 |

### 9.2 「牢狱之灾」的现代重新定义

古代「牢狱」在现代不一定是真的坐牢，包含：
- 身陷法律纠纷无法脱身（诉讼泥潭）
- 被公司/平台封杀（职业"入狱"）
- 负面舆情缠身（社会性死亡）
- 被限制出行/高消费（失信被执行人）

## 第十章：社会阶层流动的八字解释

### 10.1 八字不是宿命论

同一八字，在不同社会制度下能兑现的上限完全不同：
- 古代科举制：从农门到宰相存在可能但概率极低
- 现代市场经济：创业+投融资使得阶层跃迁窗口大大拓宽
- 现代互联网：自媒体让"伤官生财"从"手艺人"变成"网红年入千万"

### 10.2 「不适用」的坦诚标注

以下问题八字体系**无法回答**或**精度极低**，须坦诚告知：
- 精确到哪一年的具体收入数字
- 精确的子女性别（手册已裁决）
- GPS级别的精细事件时间
- 同一时辰8000人的个体差异（不在八字的设计分辨率内）

## 附录：场景推断方法论（论命时后台执行）

> 用户来找你算命，不是来填问卷的。场景探测应该在后台完成——从用户的每一句话中提取场景信号，只在关键缺口出现时用一句自然的话顺势确认。

### 一、七个场景维度

论命需要知道以下七个维度的信息，才能正确分流古典断语：

| 维度 | 需要确认的内容 | 影响哪些断语 |
|------|-------------|------------|
| 职业场景 | 打工/创业/自由职业、体制内/外 | 伤官见官、官杀混杂、财旺生官、食神制杀 |
| 财富结构 | 工资/生意/投资、稳定/冒险 | 财多身弱、比劫夺财、财旺生官 |
| 学业路径 | 正规学历/自学/考证、在读/已毕业 | 官印相生、贪财坏印、印过旺 |
| 婚姻状态 | 已婚/未婚/离异、婚恋观念 | 全部婚姻相关断语 |
| 健康基线 | 已知病史、生活方式 | 调候判断、夭寿之象 |
| 法律风险 | 职业合规风险、当前纠纷 | 伤官见官、日犯岁君、牢狱之灾 |
| 子女生育 | 已有/暂无子女、生育态度 | 全部子女相关断语 |

### 二、信号提取：用户说什么等于告诉你了什么

不需要问，用户开口说的第一段话就已经暴露了大量信息。以下是常见用户输入与场景信号的对查表：

| 用户说了什么 | 已确认的场景维度 |
|------------|---------------|
| "我今年考研" | 学业：正规学历路径→标准考试。职业：未就业/学生。年龄：约22-25 |
| "我在互联网公司做后端" | 职业：私企打工、体制外、技术岗。财富：固定工资。年龄：约22-35 |
| "我自己开了个店" | 职业：创业/个体户、体制外。财富：生意收入。风险：中等 |
| "我是公务员" | 职业：体制内打工。财富：固定工资。风险：低。学业：正规学历（已毕业） |
| "我快结婚了" | 婚姻：未婚→已婚过渡期。年龄：约25-35 |
| "我今年退休了" | 职业：已退休。年龄：约55-65。财富：退休金/积蓄 |
| "我是全职妈妈" | 职业：无薪劳动。财富：依赖配偶。婚姻：已婚 |
| "我还在读大学" | 学业：正规学历→在读。职业：未就业。年龄：约18-22 |

### 三、什么时候必须问

只有在以下两种情况下才需要主动确认：

1. **关键维度缺失且直接影响当前判断**：比如用户问"我该不该辞职创业"，但你不知道他目前在体制内还是私企——这是一组完全相反的判断。此时需要问。
2. **断语在两个场景下吉凶完全相反**：比如"伤官见官"在打工场景下凶、在创业场景下吉。如果无法从对话中推断出他是打工还是创业，需要确认。

其余情况下，用通用原则给出判断，标注"如果场景是A则…如果是B则…"即可。

### 四、怎么自然地问

**反例**（不要这样）：
> 请问你现在是在打工、创业、还是自由职业？你在体制内还是体制外？

**正例**：
> 你这个命食神生财，适合靠技术吃饭。你现在是在公司做还是自己干？因为这两种走法差别挺大的。

这句话：①先给出了一个有价值的前置判断（"食神生财，适合靠技术吃饭"），让用户觉得你已经在算。②顺势问的方向和命局分析直接相关，不是突兀的问卷调查。③用户回答后，场景信息自然到手。

**更多自然问法**：

| 需要确认的维度 | 烂问法 | 自然问法 |
|-------------|--------|---------|
| 打工/创业 | "你是打工还是创业？" | "这个格局自己干比替人打工收益大得多。你现在在做什么？" |
| 体制内/外 | "你在体制内吗？" | "原局官星不透，你不是那种一辈子待在一个单位里的人。你目前的工作环境是偏稳定还是偏市场化的？" |
| 收入类型 | "你收入是工资还是提成？" | "你财星的来源不在工资，更适合有波动有弹性的收入模式。你现在是靠固定工资还是项目/业绩类的？" |
| 考试能否过 | "你考什么试？" | "考试没问题，你的印星底子扎实，学得进去。这次考的是资格证还是升学类的？" |
| 结婚时间 | "你结婚了吗？" | "你的配偶宫要到庚寅运才被引动。如果还没结婚的话，32、33岁那两年概率很大。"（用户自然会告诉你他结婚了没） |

### 五、后台场景档案

论命过程中，AI应在思维中维护一个场景档案，随对话增量更新：

```
场景档案：
  职业：未知 → "我是程序员" → 私企打工/体制外/技术岗 ✓
  财富：未知 → 同上 → 固定工资+可能的股权 ✓
  学业：未知 → 同上 → 正规学历已毕业 ✓
  婚姻：未提及 → 待确认（但当前话题不涉及婚姻，先不管）
  健康：未提及 → 待确认
  法律风险：未提及 → 待确认
  子女：未提及 → 待确认
```

原则：只确认当前话题相关的维度。用户问事业你就别顺便问他什么时候生孩子。

### 六、与阶段0的对接

SKILL.md 阶段0加载本模块后，立即执行：
1. 从用户的第一句话中提取所有可推断的场景信号
2. 建立场景档案（七个维度，初始值"未知"）
3. 如果用户提出的问题需要用到某个"未知"维度的断语，用第四节的方法自然确认
4. 每个后续用户消息都用来更新场景档案

---

> **结语**：古典断语没有错——错的是把特定社会场景下的统计规律当成跨场景的绝对真理。本模块做的事，就是把每一句断语背后那个「默认场景」拉出来，挂上现代社会对应的场景。古人做这件事的方法是滴天髓的一句话（「不用官星尽可伤」），我们的方法是把一个场景拆成九个。
