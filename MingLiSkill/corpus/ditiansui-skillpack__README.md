# 《滴天髓阐微》六论断命技能包

清代命理大家任铁樵的《滴天髓阐微》，是子平正途上一部「重理气、反神煞」的里程碑之作——它以「五行生克制化」为唯一真理，彻底抛开神煞、星宫、纳音，用一条【旺衰 → 体用/用神 → 顺逆/通关 → 调候】的主线，把《滴天髓》四百余言歌诀逐一阐发为可操作的断法，并配以五百余例真实命例佐证。

本技能包把全书蒸馏为 **6 个断命技能**，覆盖从「定旺衰」到「断六亲」的完整断法链。

## 六个技能

| 技能 | 名称 | 覆盖范围 |
| --- | --- | --- |
| `ditiansui-tiyong-lun` | 体用论 | 取用神总纲、扶抑、病药、顺逆 |
| `ditiansui-shuaiwang-lun` | 衰旺论 | 得令/得地/得生/得助四维判旺衰 |
| `ditiansui-yuanliu-tongguan-lun` | 源流通关论 | 通关、源流、方局、形象、八格成破 |
| `ditiansui-guansha-shangguan-lun` | 官杀伤官论 | 官杀制化、伤官六用、清浊隐显 |
| `ditiansui-hanluan-zaoshi-lun` | 寒暖燥湿论 | 调候（寒暖燥湿） |
| `ditiansui-liuqin-lun` | 六亲断事论 | 夫妻子女父母兄弟、何知章、女命章 |

断法顺序建议：先 `衰旺论` 定强弱 → `体用论` 取用神 → `源流通关论` / `官杀伤官论` / `寒暖燥湿论` 看格局流通与调候 → `六亲断事论` 落到具体人事。

## 安装

将 `技能包/` 下的 6 个文件夹拷入技能目录（如 `~/.trae-cn/skills/`）即可；`候选/`、`骨架.md`、`原文/` 为断命时的模型与命例参考，建议随包保留在同级目录。

## 定位说明

本技能包源自清代《滴天髓阐微》（任铁樵阐发），其「四柱决定吉凶」的前提未经现代实证检验，命例亦多属事后附会；成书于清代，重科举官贵、沿旧式女命伦理，不可直接套用于现代职业与女性独立成就。全套内容仅作学习与娱乐参考。
