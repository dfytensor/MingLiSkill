## 第一章：论命总纲（不可跳过的标准流程）

拿到一个八字后，按以下顺序逐层推进。每一步都是下一步的前提，不可跳过。

### 第1步：定日主，察月令气候

- **操作**：
  1. 确定日干（日柱天干），这是"命主本人"
  2. 看月令地支所在月份，判断四时五行气候——寒暖燥湿
  3. 判断月令所藏人元中，何者"司令"（真神）
- **判断标准**：
  - 月令在亥子丑 → 寒（水旺金寒，万物收藏）
  - 月令在寅卯辰 → 温（木旺火相，余寒犹存于寅）
  - 月令在巳午未 → 燥（火旺土燥，水涸金熔）
  - 月令在申酉戌 → 凉/燥（金旺水相，初秋余暑，戌月偏燥）
- **常见陷阱**：
  - 辰未戌丑四库月司令复杂：辰月清明后木司令谷雨后土司令；未月小暑后火退土进气；戌月霜降后土司令；丑月大寒后土司令。不可简单以四库为纯土。
  - 调候需求≠调候优先。气候适中时（如卯月、申月），调候退位，格局进位。
- **各书共识**：渊海子平、子平真诠、三命通会、千里命稿均以"月令提纲"为论命起点。穷通宝鉴尤其强调先看月令气候。
- **各书分歧**：无实质性分歧。李虚中命书以年为本而非月令（祿命法旧制），但被子平法取代，不冲突。

### 第2步：取格局（月令透干会支定格）

- **操作**：
  1. 看月令本气是否透出天干 → 若透，直接取该十神为格
  2. 本气不透 → 看月令所藏其他之气是否透干 → 若透，取为该格
  3. 多干并透 → 择有力而无克合者取之
  4. 全不透 → 较月令人元轻重，择有力者取之
  5. 比劫/禄刃当令（甲寅月、乙卯月、庚申月、辛酉月等）→ 月令本身不可为用，必看四柱有无财官煞食透干会支另取
- **判断标准**：
  - **正官格**：甲见辛、乙见庚、丙见癸、丁见壬、戊见乙、己见甲、庚见丁、辛见丙、壬见己、癸见戊——月令透出或会局
  - **七杀格**：甲见庚、乙见辛、丙见壬、丁见癸、戊见甲、己见乙、庚见丙、辛见丁、壬见戊、癸见己——同上
  - **正/偏财格**：甲见己戊/己见甲、乙见戊己/戊见乙、丙见辛庚/庚见丙、丁见庚辛/辛见丁、戊见癸壬/壬见戊、己见壬癸/癸见己、庚见乙甲/甲见庚、辛见甲乙/乙见辛、壬见丁丙/丙见壬、癸见丙丁/丁见癸
  - **印绶格（正偏同论）**：甲见壬癸、乙见癸壬、丙见甲乙、丁见乙甲、戊见丙丁、己见丁丙、庚见戊己、辛见己戊、壬见庚辛、癸见辛庚
  - **食神格**：甲见丙、乙见丁、丙见戊、丁见己、戊见庚、己见辛、庚见壬、辛见癸、壬见甲、癸见乙
  - **伤官格**：甲见丁、乙见丙、丙见己、丁见戊、戊见辛、己见庚、庚见癸、辛见壬、壬见乙、癸见甲
  - **建禄月劫格**：日干五行与月令同五行（甲寅、乙卯、丙巳、丁午、戊巳、己午、庚申、辛酉、壬亥、癸子月），月令本身不为用
  - **阳刃格（五阳干帝旺当令）**：甲卯月、丙午月、戊午月、庚酉月、壬子月
- **常见陷阱**：
  - 月令透干被合 → 格的本质可能已被改变，不可机械取格
  - 会支改变月令性质 → 如巳丑会金局化火劫为金财（子平真诠例）
  - 官杀混杂 → 以月令为准（月令正官则正官格，月令七杀则七杀格），另一为杂，不可混称
  - 杂气财官格（辰戌丑未月）→ 不必拘泥"喜冲"之说，以透干为准（神峰通考和子平真诠均批驳"杂气喜见冲"的教条）
- **各书共识**：子平真诠的格局体系为标杆，渊海子平奠基，三命通会扩充，千里命稿整理。统一结论：以月令透干会支取格。
- **各书分歧**：
  - 渊海子平/三命通会有大量外格（飞天禄马、倒冲、子遥巳等）→ 子平真诠评注、滴天髓、千里命稿均批判或降权
  - **裁决**：外格仅在月令确实无格可取时作为补充参考（如建禄月劫格需另取财官煞食），不可优先使用。所有外格本质上可还原为正格分析。实际采信：不主动使用外格。

### 第3步：判日主旺衰强弱

- **操作**：四维判断——
  - **得令（月令旺衰）**：日干在月令的状态（旺/相/休/囚/死），权重最高
  - **得地（地支根气）**：日干在地支有无同类（通根、余气、墓库），权重次之
  - **得生（印绶生扶）**：有无印绶贴身生扶，权重再次
  - **得助（比劫帮扶）**：天干有无比肩劫财，权重最次
- **判断标准（千里命稿三级分法，精确量化）**：
  - **最强**：既当令 + 又多帮扶 → 需抑
  - **中强**：仅多帮扶而失令 → 需抑；或仅得令而少帮扶 → 需抑
  - **次强**：既不当令又少帮扶，但年日时支得气 → 需抑
  - **最弱**：既失令 + 又多克泄 → 需扶
  - **中弱**：仅多克泄而当令 → 需扶；或仅失令而少克泄 → 需扶
  - **次弱**：既不失令又少克泄，但年日时支无气 → 需扶
- **常见陷阱**：
  - **旺≠强**：得月令为旺，但不一定强——甲生寅月旺，但若干透两庚、支见酉丑合金局，党众为金而非木，旺而弱（子平真诠）
  - **衰≠弱**：失月令为衰，但不一定弱——甲生申月衰，但若比印重叠通根，衰而强
  - **"四柱无根，得时为旺"**（渊海子平）：无根但得令仍可旺；"日干无气，遇劫为强"：失令但有劫助也能强
  - **"干多不如根重"**：天干再多比劫不如地支一个真根（子平真诠评注）
- **各书共识**：渊海子平/滴天髓/子平真诠/千里命稿均以日主能任财官为"强"的标准。穷通宝鉴额外强调调候对旺衰的影响（如寒木虽旺不发）。
- **各书分歧**：滴天髓引入"众寡论"——日主旺衰不是终极标准，全局气势偏向才是。众寡论在从格判断时优先级高于日主旺衰。
  - **裁决**：先按传统旺衰四级判断，若日主极强或极弱（已到从的边界），则切换到众寡论框架。

### 第4步：分格局善恶，定顺逆方向

- **操作**：将第2步确定的格局分为"善"与"不善"两类，据此确定大方向。
- **判断标准**（子平真诠总纲）：
  - **善用神（顺用）**：财、官、印、食 → 喜生之护之
    - 官喜财生、印护
    - 财喜食生、官护
    - 印喜官生、劫护
    - 食喜身旺、财泄
  - **不善用神（逆用）**：煞、伤、劫、刃 → 需制之化之
    - 煞喜食制、印化
    - 伤喜印制、财化
    - 劫喜官制、食化
    - 刃喜官煞制
- **各书共识**：子平真诠的顺逆二分法为六书最大公约数。滴天髓虽超越格局但仍承认此框架。
- **各书分歧**：
  - 神峰通考认为"月上正官无可用之理"（官星是管我的，不能"用"），只见过用杀星多富贵人 → **裁决**：张楠此论是对"用"字的咬文嚼字，实际不影响判断。正官格的"用"是顺用而非逆用，张楠反对的是"把官当工具用"，但实战中正官格顺用的规则仍有效。
  - 滴天髓认为"勿以名之美者为佳，恶者为憎"——不用财星尽可劫，不用官星尽可伤 → **裁决**：这是病药说的哲学表达，与顺逆二分不矛盾。当官星是"病"时（如身弱官杀混杂），当然需要"逆用"官星。顺逆分类是默认方向，病药说是修正机制。

### 第5步：辨格局成败救应

- **操作**：逐项检查格局的成格条件是否满足、破格因素是否存在、有无救应。
- **判断标准**：见第二章各格局的成败条件表。
- **常见陷阱**：
  - **"成中有败，必是带忌"**：正官格有财有印看似成格，但财印相邻相克→实则破格（子平真诠薛相公命反例：壬财丁印相合→孤官无辅不上七品）
  - **"败中有成，全凭救应"**：正官格见伤官是败，但有印透制伤则反成贵格
  - **制伏太过反为病**：七杀格有食神制→成格；但食神太旺制杀过头→又变成病，需运行杀旺补救（神峰通考制杀太过案例）
- **各书共识**：子平真诠的成败救应框架为六书最大公约数。滴天髓的病药说为其哲学基础。神峰通考的实战验证加强了"制伏太过"的警惕。

### 第6步：配气候调候（必要时修正格局判断）

- **操作**：当初判格局后，回溯月令气候，检查调候需求是否满足。
- **判断标准**：
  - **极端气候 → 调候优先**（穷通宝鉴核心原则）
    - 冬月（亥子丑）无丙丁暖局 → "寒儒"，格局再高也打折扣
    - 夏月（巳午未）无壬癸润局 → "僧道孤贫"，格局再高也虚浮
  - **适中气候 → 格局优先**（春秋两季大部分月份）
    - 卯月乙木"阳气渐升，木不寒矣"，调候非刚性需求
  - **调候用神与格局用神一致 → 锦上添花，层次倍增**（穷通宝鉴五月戊土案例）
- **常见陷阱**：
  - **极端寒命用暖反凶**：滴天髓案例29→寒甚而暖无气，反以无暖为美。一暖反凶。只有在火有根时才调候有效。
  - **丁火不能替代丙火解冻**："丁乃灯烛之火，岂能解严寒之冻"（穷通宝鉴乙木冬月）
  - **癸水冻木忌用**：冬季乙木用丙不用癸，癸冻花木（穷通宝鉴重要规则）
- **各书共识**：穷通宝鉴定为调候"圣经"，滴天髓有寒暖燥湿专章呼应。子平真诠在"配气候"章承认调候重要性。渊海子平有初步调候认识（"丙丁生于冬月贵乎戊己当头"）。
- **各书分歧**：
  - 调候vs扶抑谁优先？穷通宝鉴认为调候为急，子平真诠将调候列为月令用神之后的"配"的因素，滴天髓通过寒暖篇将调候提升到天道层面。
  - **裁决**：极端气候→调候优先于扶抑。适中气候→扶抑/格局优先。具体操作：先按第4步定格局顺逆方向，再检查调候需求。若调候用神恰好是格局忌神，且气候极端→调候优先，格局退而求其次（如正月甲木用丙调候，丙为食神泄身，虽非格局最佳但仍以调候为先）。

### 第7步：论大运流年（动态判断一生起伏）

- **操作**：在格局成败+调候+旺衰综合判断后，以原局喜忌为准绳，推大运和流年。
- **判断标准**：见第五章大运流年交互规则。
- **各书共识**：渊海子平奠底，子平真诠细化，滴天髓深化，三命通会最详尽（进交退伏、交运实历等）。

| 1 | **三会 > 三合 > 六合 > 六冲 > 三刑** | 大会优先于小合，合优先于冲刑 |
| 2 | **合可以解冲**（三合六合可解冲刑） | 子年午月有丑合→合解冲。但有前提：合不被破 |
| 3 | **因解反得冲刑** | 二卯不刑一子，加戌合去一卯→一合一刑反而成立 |
| 4 | **刑冲而会合不能解** | 子年午月丑合解冲，时逢巳酉则丑会金局失合→子午复冲 |
| 5 | **先合后冲**（论先后） | 先有合后被冲→合解。先有冲后被合→冲存 |
| 6 | **天干五合同论** | 两甲合一己=争合；甲己中隔庚=合而不合（隔位太远则祸福仅得二三） |
| 7 | **本身之合不为合去** | 五阳日主逢财+五阴日主遇官→本身合之不为合去，仍可用 |

**八、实战优先级口诀**
> 三会为大，三合次之。六合可解冲刑，但须不被破。合冲并见，先看先后——先见合则冲不破，先见冲则合可解。

### 2.1 格局判定总规则

**铁律**（子平真诠+六书共识）：
1. 月令取格为第一优先级。月有用神则取月，月无用神方看他格。
2. 透干优先于会支，兼透则兼用。一透则一用，兼透则兼用，透而又会则透与会并用。
3. 比劫/禄刃/阳刃当令时，月令本身不为用，须另取四柱财官煞食。
4. 官煞混杂以月令为主取格，另一为杂。去官留煞还是去煞留官，以月令为准。
5. 外格仅当月令确实无用神可取（建禄月劫且四柱无财官煞食）时作为补充。

**六格总纲**（西山易鑑，渊海子平引）：官、杀、财、印、食、伤。阳刃和建禄月劫为特殊格。

### 2.4 格局破后有没有救？怎么救？

**救应五法**（子平真诠框架 + 滴天髓病药 + 神峰通考实战验证）：

| 破格情形 | 救应方法 | 示例 |

## 第三章：用神选取（统一规则）

### 3.1 用神选取的优先级模型

徐乐吾归纳五种取用法则（子平真诠评注）+ 八书综合后建立的优先级树：

```
拿到八字 → 
  │
  ├─ 条件A：月令气候极端（冬寒夏燥）→ 调候为急
  │   └─ 调候用神 = 优先用神（丙解冻/壬润燥）
  │
  ├─ 条件B：全局气势偏于一方，日主极强/极弱 → 专旺/从格
  │   └─ 顺其气势为用（不可逆势）
  │
  ├─ 条件C：格局有明确"病"星（伤官破官、比劫夺财等）
  │   └─ 去病之神 = 用神（病药原则优先于扶抑）
  │
  ├─ 条件D：两神对峙交战，强弱相当 → 通关为用
  │   └─ 通关之神 = 用神（木土战用火，火金战用土，土水战用金，金木战用水，水火战用木）
  │
  └─ 条件E：日主与格局力量失衡 → 扶抑为用
      ├─ 身旺格局弱 → 扶格局（如财轻身旺→食神生财）
      └─ 身弱格局旺 → 扶日主（如杀重身轻→印绶化杀生身）
```

**优先级说明**：
- A（调候）和 B（专旺）属于"结构性优先级"——一旦满足条件就优先
- C（病药）和 D（通关）属于"功能性优先级"——有病先治，有战先通
- E（扶抑）属于"常规优先级"——前三者都不适用时才走扶抑

### 3.2 调候 vs 扶抑 vs 格局用神 的冲突裁决

这是实战最大的坑。八书综合裁决如下：

| 冲突类型 | 裁决 | 理由和依据 |
|---------|------|----------|
| 调候用神=格局忌神，气候极端 | **调候优先** | 穷通宝鉴"无丙者富贵艰辛"，子平真诠"金水伤官可见官——调候为急权而用之" |
| 调候用神=格局忌神，气候适中 | **格局优先** | 卯月乙木不寒，调候非刚性，可以不用丙（穷通宝鉴） |
| 调候用神严重损伤日主 | **折中方案**：药量把控 | 正月庚金用丙暖→又虑丙过旺克金→需甲疏泄护金（穷通宝鉴）；七月壬水用戊制水→选辰戌之戊不用申中受病之戊 |
| 调候用神有替代品 | **用替代**，避免冲突 | 正月己土忌壬（冲田），则用癸替代调候（穷通宝鉴） |
| 格局用神=扶抑用神=调候用神 | **三重一致=最高层次** | 穷通宝鉴五月戊土案例：壬（调候）=财（格局喜神）=润燥（扶抑）→出将入相 |
| 气候极端但原局无调候 | **大运可补但有限** | 穷通宝鉴：原局连"种子"都没有（无一点火气），大运的补救是"外部救援"只能改善不能根本改变 |
| 身极强无需扶抑 vs 格局说需克泄 | **顺其气势，不可强行克泄** | 滴天髓"旺之极者宜泄不宜克"。阳刃格用官煞制≠普通身强用克泄，区别在于"旺极"的阈值 |

**裁决的核心逻辑**：
1. 调候是"生存条件"——气候不对，万物不生。这是第一优先级（但仅在极端气候时绝对优先）
2. 格局是"社会架构"——决定富贵天花板。这是第二优先级
3. 扶抑是"力量平衡"——决定能否撑起格局。这是第三优先级
4. 当三者冲突时：极端气候→调候优先；适中气候→格局优先；调候与扶抑冲突→折中药量

### 3.3 用神选错的补救判断

原局用神选错的表现（可在无大运信息时预判，大运来验证）：

- **错把格局当用神 vs 月令才是用神**：财格透食神，若以食神为用神（而非财），则判断偏离——"此皆由不知月令而妄论之故也"（子平真诠）
- **错把身强判断为身弱**：弱格用印→若实为身强，用印反加剧失衡
- **错把病当药/药当病**：七杀格的杀是病，但制杀太过后"制"变成病→行杀旺运为真药
- **错把假从当真从**：五月甲木假从必败（穷通宝鉴）

## 第四章：强弱旺衰（精确判断方法）

### 4.1 得令/得地/得生/得助 的量化权重

**四字分用**（子平真诠评注定义）：
- **旺**：得时为旺（月令生旺状态）
- **衰**：失时为衰
- **强**：党众为强（同类和生扶多）
- **弱**：助寡为弱

**量化权重表（八书综合）**：

| 力量来源 | 具体形式 | 权重大致比例 | 依据 |
|---------|---------|-------------|------|
| 得令（月令） | 日干在月令为旺/相 | **40%** | 渊海子平"得时俱为旺论" |
| 通根（地支同类） | 长生、禄旺 | **30%** | 子平真诠"天干得一比肩不如得支中一墓库" |
| 余气根 | 地支余气（如辰中乙木） | **15%** | 同上 |
| 墓库根 | 地支墓库（如未中乙木） | **10%** | 同上，阳墓库有根，阴墓库无用 |
| 得生（印绶） | 天干印绶贴身 | **10%** | 渊海子平 |
| 得助（比劫） | 天干比肩劫财 | **5%** | 权重最次，"干多不如根重" |

⚠️ **注意**：上述百分比权重为现代量化辅助工具，非古籍原文。八部古籍中的旺衰判断为定性三分法（得令/得地/得势），未给出过精确百分比。此表仅供参考，论命中应结合定性判断。

**关键修正**：
- **阳长生有力，阴长生不甚有力**：乙逢午、丁逢酉"亦为明根，可比得一余气"（子平真诠）
- **阳墓库有根，阴墓库无用**：甲逢未为有根，乙逢戌则无用（戌中无木藏）
- **辰戌丑未四库**：辰为湿土木之库，戌为燥土金火之库，丑为湿土金水之库，未为燥土木火之库。各自的库气表现不同，非一概而论
- **日干在四柱中的位置**：日干在地支有根（日支）> 月支根 > 时支根 > 年支根

### 4.2 "假强"与"假弱"的完整边界清单

八书综合所有看似强实弱、看似弱实强的案例条件：

#### 看似强实弱（假强）

| 场景 | 原因 | 判断标准 | 出处 |
|------|------|---------|------|
| 春木重重 | 旺而无制=旺而无用。"春木重重，休为太旺无依" | 寅卯月甲/乙木，木多但无金裁剪、无火泄秀→庸碌 | 渊海子平 |
| 夏火炎炎 | 同上。"夏火炎炎，莫作太刚有厌" | 巳午月丙/丁火，火多但无水既济→虚旺 | 同上 |
| 土厚埋金 | 印太重反而埋没日主 | 辛日地支未戌辰三土以上→金被埋，行木运破土方发 | 神峰通考 |
| 旺而弱 | 得月令但党众为克星非同类 | 甲木寅月但干透两庚酉丑会金局→金党众，甲旺而弱 | 子平真诠 |
| 四柱无根虽得令亦虚 | 无根则"虚浮在外" | 甲木寅月但四支无寅卯辰未亥→有令无根=外强中干 | 滴天髓 |

#### 看似弱实强（假弱）

| 场景 | 原因 | 判断标准 | 出处 |
|------|------|---------|------|
| 失令但党众 | 党众为强，助寡为弱 | 甲生申月衰，但天干比印重叠+地支寅亥通根→衰而强 | 子平真诠 |
| 无根但得令 | "四柱无根，得时为旺" | 甲木寅月，四支无木根但仍以旺论 | 渊海子平 |
| 无气得劫为强 | "日干无气，遇劫为强" | 甲木申月失令但天干有乙木劫财扶助→仍可论强 | 渊海子平 |

| 杀重身轻但有印 | 印化杀生身，反为贵格 | "木绝而坐金，重逢杀印，难为身弱气旺之断" | 渊海子平 |
| 衰极之木走金运反而发财 | 金生水→水间接生木（五行颠倒之真机） | 乙木四柱金土无木根，辛巳庚辰运发财 | 滴天髓案例12 |

#### 关键的"进退气"判断

| 月份 | 进气 | 退气 | 判断规则 |
|------|------|------|---------|
| 戌月（九月） | 水进气 | 火退气 | 戌月甲木→进气不死；戌月丙火→退气虽旺不生 |
| 丑月（十二月） | 木进气 | 水退气 | 丑月乙木→将进方来宜生旺 |

| 未月（六月） | 金进气 | 火退气 | 未月庚金→将进气，"三伏生寒" |

**核心规则**（渊海子平）：
> "进气死不死，退气生不生"——五行之气有进退。将进之气虽在死墓绝态也不死（本质在上升期）；将退之气虽在旺相态也气尽（本质在衰退期）。

## 第五章：大运与流年的交互论命

### 5.1 大运吉凶判断规则

**起运规则**（八书共识）：
- 阳男阴女顺行（从月柱顺排），阴男阳女逆行（从月柱逆排）
- 三天折一岁（三命通会有"零借"法，精确到时——可用但非必须）
- 大运一运管十年

**吉凶判断框架**（子平真诠+滴天髓）：

| 大运类型 | 定义 | 应事 |
|---------|------|------|
| **喜运** | 运干支助命中喜神（如官用印制伤，运助印） | 福、进益 |
| **忌运** | 运干支助命中忌神（如正官无印，运行伤） | 祸、退损 |
| **似喜实忌** | 表面助喜神，实际被合/克（如官逢印运而命有合去印） | 期望落空 |
| **似忌实喜** | 表面助忌神，实际被制（如官逢伤运而命透印制伤） | 看似凶实吉 |

**大运干支权重**（韦千里折衷法，最可操作）：
- 一运十年，前五年干占七分、支占三分。后五年支占七分、干占三分。

**大运成格变格**（子平真诠）：
- **成格**：原局格不全（如成而未全），大运补齐 → 吉
- **变格**：大运改变月令性质（如壬生亥月，运逢卯未来会亥化木，变建禄为伤官）→ 格局翻转，需重新评估

**大运与月令冲**：
- "提纲有用最怕刑冲，冲运则缓，冲用则凶"——冲大运支较轻，冲用神支或月令则重
- 月令冲大运：祸（三命通会：月令冲运则祸）

### 5.2 流年吉凶判断规则

**核心原则**：
- 太岁为一年之主宰。大运吉+流年凶→吉中藏凶；大运凶+流年吉→可解部分凶但有限
- 大运不宜与太岁相克相冲，相冲者凶（渊海子平）
- 岁运并临（大运与流年干支相同）：若损用神则有祸（三命通会·金玉赋）
- "日犯岁君，灾殃必重；五行有救，其年反必招财"——日干克流年干为犯太岁，但有救反吉

**干支并看法**（韦千里纠正）：
- 批驳"上半年看天干、下半年看地支"。干支应并看。
- 十二种干支关系：干克支、支克干、干生支、支生干等各有吉凶

### 5.5 应期判断体系（补充）


> 本模块补全手册5.4节仅覆盖"交运时间"的缺失。核心任务：回答"某事何时发生"的判断规则。

#### 2.1 引动的五种方式

【规则】"引动"=岁运（大运或流年）触发了原局的某个十神/宫位，使其发挥作用。引动是应期判断的核心概念。
【依据】滴天髓阐微·岁运章、冲合章；千里命稿·运限篇

##### 引动方式与力度

| 引动方式 | 机制 | 力度 | 判断要点 | 出处 |
|---------|------|------|---------|------|
| **透出** | 大运/流年天干透出原局地支所藏的十神 | ★★★★★ | 藏而透出→从潜在转为现实。"原局有根而运透干"应验最快。**透出后必须交叉检查**：①该十神坐下有根还是坐虚（坐虚=有名无实）②天干有无克它的字（如官透被伤官克）③有无合走它的字（如财透被比劫合走）④坐支是否为其墓库（入墓=信号被封存） | 滴天髓阐微 岁运章 |
| **冲** | 流年地支冲原局地支（用神/忌神/日支/月支） | ★★★★ | 冲用神→凶；冲忌神→吉。但极旺之神不宜冲（冲则犯旺） | 滴天髓阐微 冲合篇："得令者冲衰则拔，失时者冲旺无伤"。岳飞案例：运入辛亥，流年辛酉，酉冲卯=犯旺致死 |
| **合** | 流年天干/地支合原局 | ★★★★ | 合用神→喜事临；合忌神→解除凶象。但合化后要看化神是喜是忌 | 滴天髓阐微："喜其合而遇冲，忌其合而遇合" |
| **会局** | 大运/流年补齐三合三会 | ★★★★★ | 力量极大。会成喜局→大事发生；会成忌局→灾难 | 滴天髓阐微 案例：亥卯未会木局→岁运补齐即应 |
| **填实** | 流年填实原局空亡之支 | ★★★ | 空亡之宫位/十神被填实→该宫位/十神的事情发生。财星空亡被填实→得财；官星空亡被填实→得官；配偶宫空亡被填实→婚动 | 三命通会·论空亡："空亡…逢合则不能空" |

##### 冲的细分规则

【规则】冲的力量有方向性，不是所有冲都等价。
【依据】滴天髓阐微·冲合篇（任铁樵注）

| 优先级 | 规则 | 说明 |

#### 2.5 应期判断的操作流程

```
拿到八字，已做完第1-6步判断后→
  │
  ├─ 第1步：识别"待应事件"
  │   从原局判断：有哪些事情必定会在人生中发生
  │   （如：原局官星成格→必有升迁；原局配偶宫空亡→必晚婚）
  │
  ├─ 第2步：定位"引动条件"
  │   每件待应事件对应的引动方式是什么？
  │   （如：升迁→官星透出得力/印绶生身到位；婚姻→日支被合/配偶星透出）
  │
  ├─ 第3步：查大运
  │   在哪步大运中引动条件得到满足？
  │   → 这步大运是"发生的大时间框架"（10年范围）
  │
  ├─ 第4步：查流年（在大运框架内精确定位）
  │   → 铁律：必须按时间顺序逐年扫描忌运/喜运中的每一年，禁止只挑最出名的标签（如"岁运并临"）就定位最凶年。同一个忌运中，标签听起来不凶的年份可能因为伏吟/冲根/埋用神而实际上更凶
  │   → 哪年完全触发引动条件？
  │   → 检查该年有无冲合用神/犯旺/岁运并临等反制因素
  │
  └─ 第5步：综合判定
      引动条件满足 + 无反制因素 = 应期到了
      引动条件满足 + 有反制因素 = 被拖延/打折/反转
```

#### 常见陷阱（应期判断）

| 陷阱编号 | 陷阱描述 | 正确做法 |
|---------|---------|---------|
| Y1 | **见合就断婚动**：流年合日支不一定就是结婚，也可能是合作关系/合同签订/被合走（配偶出轨） | 必须结合配偶星是否同时被引动、十神喜忌判断合的性质 |
| Y2 | **见冲就断凶**：冲忌神是好事，冲旺神才是凶 | 先辨冲的是喜还是忌，冲者与被冲者的旺衰 |
| Y3 | **只看流年不看大运**：流年是"扳机"，大运是"枪膛"。没有大运的铺垫，流年单独触发力弱 | 先看运再看年 |
| Y4 | **把"运气好"等同于"大事发生"**：流年干支皆喜神但无冲无合→只是舒服安逸，不一定有具体事件 | 没有引动=没有应期。引动（冲/合/透/会/填实）是必要条件 |
| Y5 | **官星空亡就说一生无官**：空亡可被填实。运年填实之年就是得官之年 | 空亡≠永远空。填实的条件是流年或大运支恰好是空亡之支 |
| Y6 | **忽略"进气/退气"对时间判断的影响** | 手册4.2节进气死不死规则：将进气之五行虽在死绝也有力，将退气之五行虽在旺相也无力。这影响"何时发生"的时间感——进气者事件提前，退气者事件延迟 |
| Y7 | **只扫标签最出名的年，不逐年扫描**：看到"岁运并临"就在那年停，跳过前后年份。实际案例：己丑运中戊戌年（日柱伏吟+冲年根+埋食神）比辛丑年（岁运并临）凶得多，但戊戌年没有响亮名号所以容易被跳过 | 铁律：判断忌运中的最凶年时，必须把这十年的干支逐年列出来，逐一检查伏吟、冲根、埋用神、冲用神四个信号。标签响亮≠信号最强 |
| Y8 | **透出十神不检查反制条件**：看到官星透出就判升迁/考试，不检查该官星是否被克、被合、坐虚、入墓。实际案例：2025乙未年乙木正官透干，但乙坐未（木库=官星入墓）+ 原局庚金食神回克 → 官星被双重按住 → 考试停考而非通过 | 铁律：任何十神透出作为应期信号时，必须四连查：①坐下有无根（坐虚=有名无实）②天干有无克（被克=信号被压制）③有无被合（合走=信号转移）④坐支是否其墓库（入墓=信号封存）。四项全无问题，透出信号才算有效 |
| Y9 | **多个候选年只取最近，不往前扫**：官杀连透两年（2024甲辰、2025乙未），看到2025有信号就取2025，不回头检查2024。结果2024才是真发生了考试的那年 | 铁律：当连续多年都有同类信号透出时，必须逐年列出、逐年检查反制条件、逐年排序。取"信号最干净"的那年，不取"最近"的那年 |
| Y10 | **信号歧义时默认走"正常社会路径"**：看到伤官就判高考，看到官星就判升职——前提是假设用户的生活轨道跟大多数人一样。实际案例：2017丁酉年伤官透出，判为"高考考上"，实际是"辍学远行学手艺"——伤官在两种轨道上的含义完全相反 | 铁律：当一年信号存在两种以上合理的现实解释时，用"平行陈述"代替"单选确认"。格式："这一年[信号]，通常走A的人会[A事件]，走B的人会[B事件]。看你前面[已确认的事实]，你更像是[B]。"——陈述本身是判断，用户的反应自然验证。禁止用"你是A还是B？"直接问 |

### 6.2 婚姻

**配偶宫 = 日支**（最核心）。

**配偶星**：
- 男命：正财为妻，偏财为妾。财星得位则妻贤内助
- 女命：正官为夫，七杀可为偏夫。官星得令以安荣

**判断综合推理链**（子平真诠框架）：
1. **先看日支（配偶宫）**：日支是配偶居住的地方
   - 日支坐财官（男命坐财，女命坐官）→ 基础好
   - 日支坐伤官 → 男命不忌（伤官生财），女命大忌（伤官克官）
   - 日支坐阳刃 → 男命克妻，但身弱需刃帮身时反主妻能相关
   - 日支被冲 → 婚姻不稳
   - 日支空亡（旬空）→ 婚姻不实或晚婚
2. **再看天干透出的配偶星**：
   - 男命正财透干：财得位→妻贤；财被劫→争妻；财多身弱→妻反胜夫
   - 女命正官透干：官清秀→嫁贵夫；官被伤→克夫；官杀混杂→夫多淫乱
3. **结合大运引动**：
   - 大运来合日支（如运支与日支六合）→ 婚动之年
   - 大运冲日支 → 婚姻有变
   - 大运透配偶星（如男命运干透财、女命运干透官）→ 婚缘出现

**各书争议**：
- 女命"身弱"是否好？→ 渊海子平"女命只要身弱，主性纯粹而温柔；身强欺夫"。但三命通会"身旺夫绝、官衰食盛"为娼命→ **裁决**：女命不宜太旺，但也不能太弱逢杀重。身弱有根、官星清透为最佳。
- 配偶宫逢刑冲是否必克？→ 不是。子平真诠"妻宫坐伤官本凶，但财格逢之可生财、煞格逢之可制煞→反主妻能内助"→ **裁决**：看整体配合，不机械以刑冲论吉凶。

| 立场 | 核心观点 |
|------|---------|
| **吕才合婚书（古法）** | 以男女年命浪立数目配合——**大谬**（神峰通考明确批驳） |

#### 4.1 学业论断的三角架构

【规则】学业判断依赖三个维度：印星（学习能力）、食伤（发挥水平）、官星（功名结果）。三角必须综合判断，不可偏废。
【依据】三命通会·论印绶、论官星；渊海子平·论官星；滴天髓阐微 各案例中的"科甲""入泮"应验分析

```
        印星（学习基础）
        /              \
       /    学  业      \
      /                  \
   食伤（发挥水平）—— 官星（功名结果）
```

三者关系：
- **印星为体**——学习能力、记忆力、学历根基
- **食伤为用**——考试发挥、才华展现、临场表现
- **官星为果**——功名、考试结果、社会认可

【规则】印星代表学习能力和学历。

| 文史哲/经管/法学等传统学科 | 数理化/计算机/玄学/中医/特殊技艺 |
| 考试型人才（考什么过什么） | 研究型人才（不擅长考试但能出成果） |
| 学历含金量高，社会认可 | 可能学历不高但专业能力极强 |

#### 4.3 食伤：考试发挥与才华展现

【规则】食伤代表才华的对外展现——包括考试临场发挥、文章写作、口头表达。
【依据】滴天髓阐微 各案例中"食神泄秀""伤官生财"与科甲的关系

| 食伤状态 | 考试表现 | 行为特征 |
|---------|---------|---------|
| **食神有根吐秀** | 稳定发挥，考试心态好 | 平时怎样考时怎样，不失常 |
| **伤官有根吐秀** | 爆发力强，可以突击备考，超常发挥 | 聪明但不稳定，临场爆发 |
| **食伤被印制（枭神夺食/印制伤官）** | 才华被压制，有想法说不出，考试失常 | 平时会考时不会 |
| **食伤混杂无制** | 聪明但杂而不精，多个兴趣不专一 | 什么都行什么都不精 |
| **无食伤+有印** | 吸收型学生——学得好但创造性一般 | 适合规范性考试，不适合开放型考试 |

##### 滴天髓阐微案例支撑

- 案例：梁丞相造（丁未/癸卯/癸亥/癸丑），食神生财格→科甲连登后贵至丞相
- 案例：任铁樵自造（癸巳/戊午/丙午/壬辰），食神被戊合→虽有才华但仕途坎坷
- 案例：稽中堂造（甲子/庚午/甲子/），伤官佩印→一生宦途顺遂，文才卓著

#### 4.4 官星：功名——考试结果与社会认可

【规则】官星在原局代表"功名"——考试能否取得功名、能否在竞争中胜出。
【依据】三命通会·论官星；渊海子平·论正官

| 官星状态 | 学业/考试判断 |
|---------|-------------|
| **官星清透（一位），有财生有印护** | 功名顺遂，考试一路通关。官印双全=学霸 |
| **官星清透，无财无印** | 有竞争意识但缺乏支撑。靠自己的硬实力考但压力大 |
| **官杀混杂有制** | 经历波折后取得功名。竞争激烈但最终胜出 |
| **官杀混杂无制** | 功名蹭蹬。考试屡战屡败，或在竞争中被淘汰 |
| **官星被伤（伤官见官）** | 叛逆不遵守规则，考试失利。体制内的考核不过 |
| **原局无官星** | 没有"功名心"，对学历竞争不敏感。若无官但有食伤→靠手艺吃饭不靠文凭 |

##### 滴天髓阐微案例佐证

> "此官清印正格…异印星太重，官星泄气，神有余而精不足，以致功名蹭蹬，纵有凌云之志，难遂青钱之选"（滴天髓阐微 案例）

> "此造无印，官紧克…因之功名未遂，耗散资财"（滴天髓阐微 案例）

#### 4.5 文昌与贵人（降权辅助）

【规则】文昌贵人和天乙贵人对学业有辅助作用，但不能作为主力判断。手册裁决7只保留5种神煞，文昌为其一。
【依据】三命通会·论文昌

| 神煞 | 作用 | 注意事项 |
|------|------|---------|
| **文昌贵人** | 主文才、学习能力。文昌入命+不被冲破→读书聪慧 | **降权辅助**：文昌只是"天赋信号"，必须与印星/食伤的主判断叠加才有意义。文昌+印破=聪明但读不好书 |
| **学堂词馆** | 三命通会中有专论。学堂在长生位（甲见亥等）代表求学天赋 | **降权辅助**："学堂无气惟利师儒"——没气的学堂只是教书先生之命 |

#### 4.6 学历高低的综合判断框架

【规则】学历高低 = 印星基础 × 食伤发挥 × 官星功名 × 大运助力

##### 学历层次判断表

|---------|------|------|------|---------|

| **较高学历（硕士/好大学）** | 印星有根+不被财破 | 食伤有一即可 | 官星至少不破 | 印+食伤满足，官可有可无 |
| **普通学历（大专/本科）** | 印星虚浮或微根 | 食伤不显 | 官星不显 | 印至少微根 |
| **低学历（高中以下）** | 印被财破/印过旺为忌/原局无印 | — | — | 印星出问题=学历直接打折 |
| **学历中断（辍学）** | 印被财破在早年运 | — | — | 早年大运逢财破印 |

#### 4.7 考试运应期

【规则】考试运好的年份 = 印星/食伤被大运流年引动，且无克破之年。
【依据】基于子平法"引动=应期"原理，结合滴天髓阐微各案例中科甲年岁运分析

> **官杀连透处理规则**：当连续多年（如甲辰→乙巳→丙午）都有官杀/印星透出时，必须逐年列出、逐年检查、逐年排序，取信号最干净的一年为真考试年，不取最近的一年。逐年检查内容：①透出之十神坐支有无根（坐虚=信号弱）②天干有无克（被克=被压制）③有无被合（合走=信号转移）④坐支是否其墓库（入墓=考试被封存/停考）。四项全无问题，透出信号才算有效。

| 考试运好 | 条件 | 检查要点 |
|---------|------|---------|
| **大运在印运** | 大运天干/地支助印（印星为喜时） | 确认印星为格局喜神（不能是忌神） |
| **大运在食伤运** | 大运天干/地支助食伤（食伤为喜时） | 食神运稳定发挥；伤官运有爆发力 |
| **流年透印得力** | 流年干透印或流年支为印旺地，不被冲合 | 最直接的考试利好信号 |
| **流年透食伤得力** | 流年干透食伤或流年支为食伤旺地 | 临场发挥好，超常发挥 |
| **流年逢官星有理会** | 流年官星得力且为喜神 | 考试结果理想，功名到手 |
| **文昌贵人引动**（降权辅助） | 流年逢文昌贵人位 | 辅助天赋发挥 |

| 考试运差 | 条件 | 机制 |
|---------|------|------|
| **流年财破印** | 流年透财或支为财旺地，克破原局印星 | 因经济/家庭/感情影响学业 |
| **流年枭夺食** | 流年透偏印克食神 | 考试失常，脑子一片空白 |
| **流年冲印/冲食伤** | 流年冲印星或食伤所在之支 | 学业突然中断/考试意外 |
| **流年伤官见官** | 流年引动伤官克官 | 违犯考规/申诉无效/竞争失利 |

##### 滴天髓阐微科甲应验案例

### 8.2 纳音残留在子平法中的价值

**纳音真正的遗产**（非"海中金/炉中火"本身）：
1. **十二长生框架**：长生→沐浴→冠带→临官→旺→衰→病→死→墓→绝→胎→养——100%来自纳音法，被子平法平移使用

3. **干支关系的思维模式**：刑冲克害合的逻辑，纳音法已完全建立

**纳音 vs 正五行之争**（裁决21补充）：唐代以前以纳音论命为主流（李虚中命书为代表），宋代徐子平改以日干正五行为核心。此后子平法完全取代纳音法成为主流。本手册采信子平法立场的理由是：①正五行生克逻辑可操作、可验证，纳音的"海中金""炉中火"取象模糊不可证伪；②穷通宝鉴/神峰通考/滴天髓三大实战典籍均以正五行为论命主干；③纳音的真正遗产（十二长生、神煞骨架、三元思维）已被子平法吸收，其独有的六十甲子纳音分类已无独立使用必要。**论命中如需参照纳音（如力量层级交叉判断），必须标注"降权80%"。**

## 附录：胎元/命宫/身宫（三垣简述）

> **本手册立场**：三垣在子平法实战中已被边缘化，不纳入主流程。以下为背景知识，论命时如需提及须标注"降权参考，非判断依据"。

### 胎元

**计算**：以月柱干支为基准。月干顺推一位，月支顺推三位。如甲子月→胎元乙卯。

**古籍地位**：
- 李虚中命书以胎元为重（"胎月见贵，必受福荫"），三命通会有专论
- 子平真诠、滴天髓、穷通宝鉴均不以胎元论命

**实战定位**：
- 胎元纳音与日主纳音的关系可作先天禀赋参考（降权80%）
- 但不可因此推翻四柱正五行判断。手册6.3节中引用的"胎月权重2/10"（据传引自李虚中命书）即为此背景——李虚中体系以胎元为轻重，但被子平法取代

### 命宫

**计算**：以生月数至生时。如子时生人，正月→命宫在寅，卯月→命宫在卯……逆推至生时。具体口诀见三命通会。

**实战定位**：
- 命宫神煞（如命宫坐天乙贵人）可作辅助参考
- 子平真诠和滴天髓均不以命宫参与格局判断
- **本手册不采信命宫论命法**

### 身宫

**计算**：以生时数至生月。如子时生人，正月→身宫在子。

**实战定位**：
- 仅在李虚中命书和三命通会中有系统使用
- 子平法完全不论身宫
- **本手册不采信身宫论命法**

### 裁决

三垣是禄命法（李虚中）的遗产。子平法以日干为核心的四柱体系已完全覆盖三垣功能——胎元的信息被月柱吸收（月柱管早年），命宫的信息被日柱吸收（日柱管自身），身宫的信息被时柱吸收（时柱管归宿）。三垣作为独立判断维度实战价值极低，仅作学术背景保留。

> - **[注5] 己土寅月**：通行版作「丙→甲→庚」，徐注作「丙→庚→甲」。徐注逻辑：先解冻(丙)，再制病(庚制甲)，后酌用甲。次序调整不影响丙为第一调候。本表从徐注。
> - **[注6] 己土申酉月**：通行版作「癸→丙」，徐注作「丙→癸」。申酉月金泄土虚，丙火生土应优先于癸水润土。梁湘润、何重建一致支持徐注。本表从徐注。
> - **[注7] 庚金未月**：通行版作「丁→甲」。徐注：未月金进气火退气，壬水润金优于丁火炼金。梁湘润从徐注。本表从徐注，但论命中若原局火炎土燥仍不可轻弃丁火。
> - **[注8] 癸水丑月**：通行版作「丙→辛」，徐注作「丙→丁」。丑月寒极，丁火暖局优于辛金发源。但若原局水旺无金，辛金仍为要药。本表从徐注，论命中需视原局金水力量取舍。
>
> 除上述 8 条外，本表还对 32 处通行版遗漏的辅助调候做了补全（如丙火卯月缺己、丁火未月缺庚等），不再逐条标注。完整差异清单见下方「附录A附」。

## 附录B2：完整推理案例

### 完整推理案例1：岳飞

**四柱**：癸未 乙卯 甲子 己巳

**为什么选它**：格局→成败→阳刃→冲合→夭寿，一条完整因果链，且原局无刑冲凶煞却横死，必须穷尽推理才能找出真正的杀机。

---

**第1步：定日主，察月令气候**
- 日主甲木，生于卯月（仲春）
- 气候温暖，木当令，调候非刚性需求，此步无优先干预

**第2步：取格局**
- 月令卯 → 卯中藏乙木，甲日见卯为阳刃（甲帝旺在卯）
- 阳刃格。阳刃为不善用神，需逆用——找官煞制刃
- 检查四柱有无官煞：天干无庚辛金透出。年支未中藏辛金正官、时支巳中藏庚金七杀，但都深藏不透 → **官煞不出，制刃之力大打折扣**
- 格局判定：阳刃格，官煞深藏不透=制刃不力

**第3步：判旺衰**
- 甲木卯月得令（旺）+ 日支子水正印癸水贴身（得生）+ 年支未为木库（得地）+ 天干乙木劫财（得助）
- 四维全满 → **极旺**
- 极旺的甲木阳刃格，官煞又深藏不退，这正是"刚极易折"的结构

**第4步：分顺逆→辨成败**
- 阳刃格，逆用，需制。判断标准：官煞透干制刃=成格；官煞不透=败格
- 此造官煞深藏→**初判为败格**

**第5步：寻救应，找"病"和"药"**
- 这是最关键的一步。两个"看似是救实则是杀"：
  
  ① **卯未半合木局** → 合刃。阳刃被合在传统阳刃格中是好事（"合刃"相当于间接制刃）。但注意：未是木库，卯是刃，半合木局=**刃更旺**，不是制刃是助刃！这恰好是"合"的反效果
  
  ② **巳酉丑合金局（巳+??+??）** → 这里需要仔细检查：四柱有巳（时支），有酉吗？——**没有。四柱中无酉无丑，巳酉丑合金局不成立**。所以巳中庚金七杀仍在但深藏不透，制刃之力远不够
  
  ③ **子卯相刑** → 子水（癸水正印）与卯木（阳刃）为子卯相刑。子水印绶本来生甲木日主是有情之生，但子卯相刑后**印绶失其正而生之不正**。"子刑卯，卯刑子"——母（印）子（日主）之间产生了刑的关系
  
  ④ **己土正财坐巳火伤官之上** → 己土克癸水（正财坏正印），而癸水是正印！按"贪财坏印"的大忌，这又是在阳刃极旺格局上叠加的致命一击——唯一能化刃的印绶被财星克了
  
  ⑤ **最致命的组合**：亥卯未三合木局！运入辛亥运时，亥字一到→亥卯未三合木局完成。再遇辛酉年，酉冲卯（阳刃逢冲）。合刃（亥卯未）与冲刃（卯酉冲）同时发生→阳刃被三合又被冲，双重激活，刚极必折

- **病的最终定位**：阳刃极旺无制是"病"。深藏的辛金官星和庚金七杀是潜在的"药"但力量太弱。巳中的庚金七杀被己土财星所生→财生杀→杀在巳火之上被火所制（火克金），药力被进一步削弱

**第6步：大运印证**
- 运走辛亥→亥卯未三合木局完成，刃更旺
- 流年辛酉→酉冲卯（阳刃逢冲），同时辛金正官透干——官星终于透出！但悲剧在于：**透出的辛金官星是与太岁酉金一起来的，而酉金冲卯木阳刃，官星和阳刃同时被激活且互相冲战**
- 酉冲卯=官冲刃。阳刃格被官星冲，原本"官制刃"是好事，但此造的问题是：阳刃太旺而官星只在流年才透，一年的药治不了四十年的病。官星透出反而激怒了阳刃→"犯旺"——和滴天髓案例27中"丙运犯其旺神死于军中"同一种致命机制

**第7步：最终结论**
- 表面看：阳刃格、官煞深藏、无冲无破，似乎平安
- 实际看：印被财坏、刃被合而更旺、最终在运到亥（合刃）年逢酉（冲刃）时——合与冲同时发生，激怒旺神
- 渊海子平原文结论："金多见甲，身虽贵，亦遭刑也；然虽见辛为贵，所忌阳刃，不可一合一冲也"

**核心规则提炼**：
1. **合刃不一定是好事**——卯未半合木局让刃更旺而不是制刃
2. **深藏的官煞在阳刃格中不是"有就行"**——必须透干有力才能真正制刃
3. **阳刃格最忌"一合一冲"同时发生**——这就是岳飞横死的推理解释
4. **"贪财坏印"在阳刃格中尤其致命**——印是化刃的唯一柔性力量，被财克则最后的保护也消失
5. **流年透官冲刃=犯旺**——不是制刃，是激怒刃

### 完整推理案例2：任铁樵自造

**四柱**：癸巳 戊午 丙午 壬辰

**为什么选它**："一字定生死"的经典——任铁樵以自己的人生验证滴天髓理论，全书最震撼案例。

**第1步：定日主，察月令气候**
- 日主丙火，生于午月（仲夏）

**第3步：判旺衰**

**第4步：分顺逆→辨成败**
- 阳刃格核心：需官煞制刃
- 但这里有个致命悖论：官杀确实透出了！癸为正官制刃、壬为七杀制刃→表面上满足"官煞制刃"
- 然而官杀混杂+官杀无强根→制刃之力远远不够。阳刃极旺而官杀极弱→**这不是制刃，这是触怒旺神**

**第5步：寻救应与病药——"一字定生死"**
- 任铁樵自己指出了关键对比：他与另一人（癸**丑**/戊午/丙午/壬辰）仅年支一字之差
  - **彼造（丑年）**：丑=北方湿土→晦火蓄水藏金。丑中藏癸水（正官有根）、辛金（正财）、己土（伤官）→金生水+癸水通根=七杀壬水的后援。丑是湿土，能晦火，把过旺的火势压下来
  - **此造（巳年）**：巳=南方火土→火之禄地+金之长生。巳中藏丙火（比肩帮身→旺上加旺）、戊土（食神泄秀→稍微泄火但不够）、庚金（偏财→金生水但火旺金熔）→巳年不仅不制火，反而**助火**。巳是燥土，燥土助火

- **戊癸合的致命性**：年干癸水正官与月干戊土食神相邻。戊癸合（天干五合）。彼造（丑年）戊癸合而不化，癸水仍有独立作用。此造（巳年）巳火猛烈，**戊癸合而必化火**！化出的火反过来助阳刃猖狂

- **壬水的孤立**：时干壬水七杀坐了辰水库（唯一的根），但：①年支巳中庚金被旺火熔，②戊癸合化火后全局无水之源，③辰为湿土水库，但丙午日主两午火+戊癸化火，辰这一库水根本济不了滔天烈焰

- **病的定位**：阳刃极旺是"病"，官杀混杂无根是"假药"，戊癸合化火是把唯一的解药变成了毒药

**第6步：大运——走向深渊**
- 任铁樵自述：运走四十载木火生助劫刃之地
- 木运→生火；火运→助火。每一步都在浇油
- 至卯运→卯木生火，壬水在卯为死地→壬水最后的微根被彻底消灭
- "遭骨肉之变倾家荡产"

**第7步：最终结论**
- 任铁樵自己的原话："清枯之象"
  - **清**：格局似乎清楚——阳刃格、官杀透出。但不是真清
  - **枯**：无生发之意——水无源、金无力、只有火在烧。枯=死水养不了鱼
- 命运对比：巳年vs丑年，一字之差，天渊之隔。丑年造有救（湿土晦火+金生水），巳年造无救（燥土助火+金被熔）

**核心规则提炼**：
1. **阳刃格官杀必须透干有根**——无根的官杀制不了阳刃，反而触怒旺神
2. **戊癸合在火旺的巳年合而化火**——合的吉凶取决于月令旺衰（这是天干五合的实战关键）
3. **"一字之差"的根源在寒暖燥湿**——丑（湿土晦火）vs巳（燥土助火），滴天髓的燥湿论在此达到极致
4. **"清枯之象"的判断标准**：日主极旺+用神孤立无源+满盘只有一种五行得势=看似清实为枯
5. **任铁樵的自我验证**是对滴天髓理论最残酷也是最有力的证明——他以一生潦倒换取了对理论的信仰

### 完整推理案例3：五月戊土极品

**四柱**：辛未 甲午 戊寅 壬子

**为什么选它**：穷通宝鉴中的顶级格局——调候与格局完美一致，反面验证了"调候=格局用神则层次倍增"的规则。穷通宝鉴评语"出将入相，名播四夷"。

---

**第1步：定日主，察月令气候**
- 日主戊土，生于午月（仲夏）
- 午月=火旺土燥。气候极端燥热
- **调候为急**：戊土午月的刚性需求是"壬甲丙"（穷通宝鉴口诀："仲夏火炎，先看壬水，次取甲木，丙火酌用"）
- 壬水=第一调候用神（解炎润土），甲木=第二（疏土），丙火=第三（有则加分）
- 此造壬水透于时干+甲木透于月干→**第一和第二调候用神全透！**

**第2步：取格局**
- 月令午 → 午中藏丁火（正印）+ 己土（劫财）
- 丁火正印当令 → 印绶格（丁为戊土之正印）
- 天干透出：年辛（伤官）、月甲（七杀）、时壬（偏财）
- 格局：印绶格。喜官星来生印→但此造透出的是甲木七杀而非正官
- 印格用杀的判断（子平真诠）："印轻逢煞"→需印有不足才喜杀来生。此处午月火旺印不轻，但：日支寅木生午火（木生火=杀生印），甲杀→午印→戊日主，形成**杀印相生**的流通链
- 格局判定：印绶格+杀印相生。福格。

**第3步：判旺衰**
- 戊土午月得令（旺，火旺土相）+ 日支寅中藏戊土（余气根，得地）+ 月干甲木七杀克身（克泄）
- 杀被印化，克身之力转为生身之力（甲→午→戊=杀生印生身）
- 综合判断：**偏强但不极强**。身足以任财官，又不至于旺极无制。
- 旺衰度恰好——这就是格局"有情"的基础

**第4步：分顺逆→辨成败**
- 印绶格为善用神，顺用——喜官星生印、忌财星破印
- **常规风险**：时干壬水偏财克午火印绶→财破印！这是印格的经典破格条件
- **但这个造例外在哪里？**
  1. 午月调候必须以壬水解炎为第一优先。壬是调候用神，即使它在格局层面是财（破印），调候优先于格局常规
  2. 壬水被甲木通关保护：壬水→甲木→午火。壬水生甲木（财生杀），甲木生午火（杀生印），午火生戊土（印生身）。壬水不但不破印，反而通过甲木间接生印！这就是**通关**的精妙之处
  3. 辛金年干的作用：辛金生壬水（伤官生财）→壬水有源头

- 行运配合验证（穷通宝鉴原文未详述大运，但方法论可以推导）：
  - 若行金水运：辛金生壬水→财更旺→甲木通关→杀印更旺→官运亨通
  - 若行木火运：甲木更旺→杀印相生更强→权位更高
  - 全方位顺遂，没有死角

**第5步：格局最终判定**
- 穷通宝鉴对此造的评语："壬甲两透，印旺杀高，出将入相，名播四夷"
- 翻译成手册规则语言：
  - ① 调候满分：壬（第一优先）透+甲（第二优先）透
  - ② 格局完美：杀印相生（甲杀→午印→戊日主），杀不克身反成权威
  - ③ 通关有情：辛生壬→壬生甲→甲生午→午生戊。完整的四步流通链
  - ④ 调候用神=格局喜神（壬=调候+财；甲=调候+杀）→双重加分
  - ⑤ 全盘无破：壬不伤午（有甲通关），甲不伤戊（有午通关），辛不克甲（隔位且辛生壬）

**第6步：反面对比验证**
- 假设同一格局但没有调候：午月戊土+杀印相生，但无壬透 → 格局虽好而调候缺位 → "火炎土燥"，顶多中等富贵，"僧道孤贫"的风险仍在
- 假设有壬透但没有甲通关：壬直接克午印 → 财破印 → 贪财坏印，贵气大打折扣
- **这个造的不可复制性**：壬、甲、辛三者的位置关系是天成——壬在时、甲在月、辛在年→顺生不逆。如果甲在年、壬在月，生克顺序就完全不同

**第7步：核心规则提炼**
1. **调候用神=格局用神时，命局层次翻倍**——这是穷通宝鉴的"君臣庆会"格
2. **通关是调候和格局和解的唯一机制**——壬水（财/破印）通过甲木（杀/通关）生午火（印），财的破坏力被转化为印的增强力
3. **位置决定一切**——辛→壬→甲→午→戊的顺生链，每个字都在正确的位置上
4. **反面验证同等重要**——有壬无甲=破格；无壬有甲=层次大降；两者全有且位置对=极品
5. **穷通宝鉴的调候不是孤立的**——五月戊土"先看壬水，次取甲木"是总结，但壬甲之间的关系（通关）才是这个命从"好"变成"顶级"的关键
